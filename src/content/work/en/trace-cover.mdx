## Background

Long-document retrieval systems can return evidence that looks relevant while still missing important parts of the source material. For review, compliance, and requirements tracing, that gap matters more than whether one answer looks good.

## The idea

A benchmark should ask not only whether retrieved evidence is relevant, but whether the system can explain which evidence paths it covered and which ones it did not.

## What I built

TRACE-Cover is a research harness for requirement-evidence traceability in long multimodal documents. The focus is low-cost model collaboration, coverage evaluation, and explainable evidence paths.

## Where it is now

- Trace path concept
- Evidence coverage visualization
- Benchmark representation
