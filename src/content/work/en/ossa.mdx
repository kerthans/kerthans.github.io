## Background

Many product ideas start as opinions. The source is unclear and the evidence is unstable. Ossa treats opportunities as observable events before treating them as product ideas.

## The idea

If a system starts with sources, event types, and evidence, opportunities can emerge from observation instead of brainstorming.

## What I built

The system starts from an observation source, records an event, preserves evidence, and then decides whether it becomes an opportunity. The internal model still follows source, event, evidence, opportunity, but it does not need to behave like a slogan.
