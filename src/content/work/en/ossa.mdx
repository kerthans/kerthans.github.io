## OBSERVATION

Ideas often arrive as opinions. Ossa treats opportunities as observed events with evidence trails.

## THE BET

If a system starts from stations, events and evidence, opportunities can be surfaced as observed phenomena instead of brainstorming output.

## WHAT I BUILT

The model follows Station -> Event -> Evidence -> Opportunity: observe a source, type the event, preserve evidence, then decide whether action is warranted.
